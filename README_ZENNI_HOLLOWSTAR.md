# Zenni & The Hollow Star — CoCX content expansion

An in-progress content expansion for Corruption of Champions Xianxia, **based on the CoCX 0.9a.995 source code**. The content was developed against that specific source snapshot, not the latest upstream master.

## Content

- Zenni's Cliffs laboratory, research and sample progression, personal dialogue, shop and combat encounters.
- Four research samples: True Dragon, Sphinx, Siren, and Manticore. Sample collection raises trust from level 1 to 5.
- Independent companion behavior, combat actions, survival mechanisms, and a betrayal route.
- Four accidentally sentient creations: Seraphine, Vespera, Ember, and Frostwhisper.
- Hollow Star containment annex, ten composite encounters, environmental hazards, a two-phase Warden, and the Hollow Star Concordance reward.
- Original sprites for Zenni, her daughters, the Hollow Star composites, and the Warden.

## Integration and testing

Zenni-specific scenario testing options are available through the existing debug menu, including sample presets and encounter tests. These are intended for development and should be omitted from a production release if the project maintainers prefer.

Build with the project's Apache Flex configuration and the required Flash Player libraries. Original game font assets are not redistributed in the contribution package; provide them in their expected source locations when building.

This is a work-in-progress submission. The cleaned source was compiled successfully with Apache Flex, but full interactive gameplay, combat, progression, and save/load testing remain outstanding.

## Scope

Android-specific layout adjustments, fullscreen changes, and unrelated debug shortcuts or mass-unlock controls are not included.
