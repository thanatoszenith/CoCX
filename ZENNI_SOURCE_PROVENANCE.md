# Zenni & The Hollow Star — Source Baseline

**Development base: CoCX_0.9a.995 (the CoCX_0.9a.99 series).**

The content expansion was developed and compiled against the **CoCX v0.9a.995** game source, not the older `v0.9a.731-732` revision currently present on this fork's `master-wip` branch.

## Contribution scope

Zenni's laboratory, sample progression and trust, combat and companion features, four daughters, the Hollow Star containment dungeon, the two-phase Warden, supporting dialogue, and original sprites.

The development source excludes Android fullscreen adjustments and unrelated personal debug shortcuts. The content is still undergoing gameplay testing.

## Source and build notes

The integration is maintained on `zenni-hollow-star`. The development SWF is built from the CoCX 0.9a.995 source snapshot with Apache Flex. The original game's build dependencies and licensed fonts are required when compiling.

Because the fork's upstream `master-wip` currently identifies itself as `v0.9a.731-732`, this branch must not be merged into it without first reconciling the game-version baseline. A pull request should target a matching CoCX 0.9a.99-series source revision.
